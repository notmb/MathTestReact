## Features

- Create test variants
- One-time test links for students
- Save test results to Firestore
- Dynamic forms for answers
- Custom client-side routing (implemented without React Router)

## Tech Stack

- React
- TypeScript
- Firebase (Firestore, Storage)
- Vite
